# Karthik's Product Portfolio

Live at **https://karthik07p.github.io**

PRDs, prototypes and analyses from B2B SaaS and AI products, built as a hand-written static site.

## Case studies
- **CUBE: fixing the trial-to-paid drop-off**: funnel analysis, PRD and clickable prototype
- **SwasthyaSaathi**: vernacular GenAI triage assistant, live web app
- **AI Try-On**: PRD for AR jewellery try-on
- **Microsoft Link to Windows**: product teardown
- **Problem framing**: 5W1H on two open-ended product problems

## Built with
Plain HTML, CSS and JavaScript, with no framework or build step. Hosted on GitHub Pages. Light and dark themes.

## Run locally
```
python -m http.server 8765
```
Then open http://127.0.0.1:8765/
